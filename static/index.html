Đăng Shopee hàng loạt 🚀

Dán danh sách link sản phẩm Shopee của bạn vào ô dưới đây (mỗi dòng một link) để hệ thống tự động bóc tách và xếp lịch đăng bài.

📅 Nhập lịch đăng từ Claude

Paste lịch đăng bài dạng JSON từ Claude, điền link Shopee sản phẩm và bấm Import để tự động tạo toàn bộ bài đăng theo lịch. Link Shopee sẽ tự động bình luận dưới mỗi bài sau khi đăng.

Link này sẽ được tự động bình luận dưới mỗi bài đăng sau khi đăng thành công.
Định dạng JSON: mảng các object gồm name, content, scheduled_at, target_id, type (group/profile/page). Hoặc tải file .json bằng nút bên trên.

📊 Kết quả nhập lịch

📖 Hướng dẫn

  1. Mở Claude share link của bạn và copy toàn bộ lịch đăng bài dưới dạng JSON.
  2. Paste JSON vào ô Dữ liệu lịch đăng ở bên trái.
  3. Điền link Shopee sản phẩm vào ô Link Shopee.
  4. Chọn tài khoản Facebook sẽ đăng bài (hoặc để trống để dùng tài khoản đầu tiên).
  5. Bấm Import & Lên lịch tất cả.
  6. Hệ thống sẽ tạo toàn bộ bài đăng theo đúng lịch. Link Shopee sẽ được tự động bình luận dưới mỗi bài sau khi đăng.

Lưu ý: Bạn có thể chỉnh sửa nội dung từng bài sau khi import tại tab Lịch sử & Hẹn giờ. Link Shopee có thể thay đổi bất kỳ lúc nào trong phần Cấu hình hệ thống → Mẫu bình luận Shopee.
